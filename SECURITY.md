# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Koris Assistant, please open an issue on [GitHub Issues](https://github.com/guilhermesalviano/koris/issues) describing:

- The affected version/commit.
- Steps to reproduce.
- The potential impact.

We'll acknowledge the report and follow up with next steps. Please avoid publicly disclosing exploit details until a fix has been released.

## Scope

This project also runs automated [CodeQL](.github/workflows/codeql.yml) analysis on a schedule to catch common vulnerability patterns in the TypeScript codebase.
